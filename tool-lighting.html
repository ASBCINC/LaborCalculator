Positions run left to right in the wall box, so the gang count is the number of positions. Dimmer, switch and fan control are the loads. A companion (3-way) at another location controls a load with the same label, and the tool flags a companion whose label doesn't match a load in the room. Labels double as engraving text. Room types are only starting points. Before pricing, check every load's type (LED, ELV, MLV, 0-10 V) and wattage, and check the system's device limits, in Lutron Designer.
