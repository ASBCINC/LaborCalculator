Standard class limits at the switch: 802.3af (PoE) 15.4 W, 802.3at (PoE+) 30 W, 802.3bt Type 3 (PoE++) 60 W, Type 4 90 W. The class limit is the worst case; real draw is usually lower, so the spec-sheet max is the better number. Many switches only reach full budget with a second power supply.
